# jma_navigator（気象庁ナビ）

気象庁ホームページで「知りたい情報」のページへたどり着くための**案内アプリ**です。
「名護市の警報は出ている？」「今日の最高気温ランキング」のように日本語で聞くと、**該当する気象庁のページを、地域・地点・日付まで指定した状態で**案内します。

詳しくは [jma-navigator.md](jma-navigator.md)（設計メモ・判断の経緯・Q&A）を参照してください。

- **公開版**: https://jma-navigator.onrender.com （URLを知っている人向け。検索には載せていません）
  - Render の無料プランのため、しばらくアクセスがないと、初回は起動待ちで数十秒かかります。
- 個人が運営する**非公式**のサービスで、気象庁とは関係ありません。気象の解説や、防災行動の判断は行いません。
- 標準ライブラリだけの Python（開発は 3.11）と、フレームワークなしの JavaScript で作っています。**LLM は使っていません**（任意で試せる版はありますが、公開版では無効です）。

## 1. 何ができるか

| 聞き方の例 | 案内されるもの |
|------------|----------------|
| 明日の那覇の天気 | 那覇（沖縄本島地方）の天気予報 |
| 名護市の警報は出ている？ | 名護市の警報・注意報（地域の単位は 全国／地方／府県／市町村 から選べる） |
| 大雨の見通し／沖縄の大雨の見通し | 警報等の時系列、早期注意情報（全国→地域を指定すると、その地域） |
| 名護市の気象台からのコメント | 気象庁「あなたの街の防災情報」のページ ＋ **予報官の文章をそのまま表示** |
| 台風の進路 | 現在の台風の経路図 |
| 今日の最高気温ランキング | 今日の全国観測値ランキング（次点に一覧ページ） |
| 那覇の満潮はいつ？／名護市の潮位 | 潮位の観測所（観測所がない市町村は、同じ地方の観測所を候補に） |
| 波の高さを知りたい | 波浪実況・予想図（全国／沿岸の海域） |
| 去年の8月の那覇の気温 | 過去の気象データ（日ごとの値）の該当地点・年月のページ |
| 今日の夕方、名護市の海に行きたいけど、天気は大丈夫？ | 名護市の天気予報 ＋ 警報・注意報、早期注意情報など（安全かどうかは断定しません） |

- 案内先は**すべて気象庁のページ**です（サーバーと画面の両方で、`www.jma.go.jp` と `www.data.jma.go.jp` 以外のリンクは出しません）。
- 質問があいまいなときは、**候補を複数**（本命1件＋次点最大4件、理由つき）出し、「このページで合っていましたか？」で**絞り込み**（いつの情報？何について？）ができます。
- カタログは27項目（天気・防災・海・長期予報・過去データ・観測）。地域の単位に対応する項目は、画面の「地域の単位」ボタンで切り替えられます。

## 2. 使い方

### 公開版
https://jma-navigator.onrender.com を開き、質問を入力するか、入力例のボタンを押します。

### 手元で動かす
```bash
git clone https://github.com/masauehr/jma_navigator.git
cd jma_navigator

python3 server.py                  # http://127.0.0.1:8765/ を開く（使用中なら --port 8791 など）
python3 -m jnav "明日の那覇の天気"   # 画面なしで結果のJSONを表示
python3 -m unittest discover -s tests   # テスト
```
追加のインストールは不要です（`requirements.txt` は空）。`server.py` は `127.0.0.1` にだけ待ち受けます。

## 3. 仕組み

気象庁のページの多くは、**URLだけで表示内容が決まります**（例: `warning/#area_type=class20s&area_code=4720900`）。そこで、画面の中身を読んで押す場所を探すのではなく、**質問からURLを直接組み立てて**案内します。LLM にURLを作らせないので、誤っても「別のページが開く」止まりで、でたらめなURLにはなりません。

```
質問文
  │
  ▼ ① 地名を探す        地名辞書（予報区・市町村・アメダス・気象官署・潮位観測所）から決定論的に
  ▼ ② ページを選ぶ      カタログ27項目に点数を付けて、本命と次点を決める
  ▼ ③ 地域の単位を決める  全国 / 地方 / 府県 / 市町村（地名の粒度、または利用者が選んだもの）
  ▼ ④ URLを組み立てる    カタログのテンプレートに値を埋める（自由に文字列を作らない）
  ▼ ⑤ 返す              本命 ＋ 次点 ＋ 絞り込みの選択肢（＋気象台のコメント）
```

### ① 地名を探す（`jnav/areas.py` ほか）
質問文の部分文字列を、気象庁の地名辞書に当てます。「名護市」は 沖縄本島地方 の市町村、「石垣島」は 八重山地方、「東京」は 東京都、のように決まります。

| 辞書 | 用途 |
|------|------|
| `data/area.json` | 地方（11）・予報区（58）・一次細分・市町村。気象庁 `area.json` の写し |
| `data/amedas_stations.json` ほか | アメダス観測所 約1,300地点（緯度経度・観測要素つき） |
| `data/etrn_stations.json` | 過去データ検索用の気象官署 153地点（`prec_no`・`block_no`） |
| `data/tide_stations.json` | 潮位観測所 166局 |

- 複数の予報区にまたがる地名（「府中」→ 東京都・広島県）は**勝手に決めず、候補ボタンで聞き返し**ます。
- 「北海道」のように複数の予報区にまたがっても、すべて同じ地方（北海道地方）に属するなら地方が決まります。「関東」「九州」などの通称、山口県が九州北部地方に属すること、「沖縄」は沖縄地方全体を指すこと、なども扱います。

### ② ページを選ぶ（`jnav/suggest.py`、`catalog.json`）
`catalog.json` が、案内できるページの**正本**です。1項目が1ページで、主な項目は次のとおりです。

| キー | 内容 |
|------|------|
| `intents` | 想定する言い回し（気象庁の画面上のページ名もそのまま入れる） |
| `url` / `scope_urls` | URLのテンプレート（`{office_code}` `{class20_code}` `{center_code}` など）。地域の単位ごとのURLを持てる |
| `params` | 必要な値（地域・観測所・日付）と、その決め方 |
| `tags` / `when` | 話題（雨・台風・海…）と時間軸（今・これから・過去） |
| `related` / `exclude_words` | 必ず次点に添えるページ／対象外にする語（「歴代」など） |
| `verified` | 実際のページで内容を確認したか |

点数は次の合計です（LLM なし・決定論的）。

```
点数 = 一致した言い回しの長さの合計
     + 話題の一致 × 4
     + 時間軸の一致 ±3
     + 地名があれば、地域を指定して開けるページに +2（地名がなければ −1）
     + 利用者が「違う」のあとに選んだ絞り込み ±8
```
- 最上位が本命、点数の近いものが次点（最大4件）です。
- 話題だけが一致して**決め手がない**質問（「雨が心配」）は、本命を決めず「どれに近いですか？」と候補と絞り込みを出します（根拠のないページを自信ありげに出しません）。
- 語彙表（話題・時間軸）は、`suggest.py` の `TOPICS` / `WHEN` にあります。「海」「波」「大丈夫？」「夕方」のような語を足すと、拾える質問が増えます。

### ③ 地域の単位（`jnav/navigate.py`）
警報・注意報は市町村ごとに発表されるなど、ページによって地域の細かさが違います。

| 単位 | 例 | 対応ページ |
|------|----|------------|
| 全国 | 全国の地図 | 警報・注意報、警報等の時系列 |
| 地方 | 沖縄地方（沖縄本島・大東島・宮古島・八重山をまとめた単位） | 警報・注意報、時系列、早期注意情報、府県気象情報 |
| 府県 | 沖縄本島地方 | 上記 ＋ 天気予報 |
| 市町村 | 名護市 | 警報・注意報、時系列、天気予報 |

**市町村名そのもの**が書かれていれば市町村、略称や県名なら府県、地方名なら地方、地名がなければ全国、を既定にします。結果カードの「地域の単位」ボタンで切り替えられます。**どの単位がどのページで開くかは、Chrome で1つずつ確認**しています（気象庁側が対応していない単位は出しません）。

### ④ 特別な扱いがあるもの
| 項目 | 内容 |
|------|------|
| 潮位（`jnav/tides.py`） | URLに「市町村・観測所・沿岸区分」の3つが要る。観測所名→市町村→同じ予報区の順に決め、決まらなければ観測所を候補ボタンに出す |
| 日別ランキング | URLが `data{月日}.html`。質問から今日・昨日・「10月28日」を読む（**日本時間**）。掲載は最近1週間分だけなので、範囲外は一覧ページと理由を案内 |
| 過去データ | 気象官署の `prec_no`・`block_no` と年月（「去年の8月」「先月」）を質問から決める |
| 気象台からのコメント（`jnav/comments.py`） | 案内に加えて、予報区ごとの文章を**要約せず全文**そのまま表示。発表日時と出典つき。5分キャッシュ、12時間を超えたら「古い可能性」を表示 |

### 結果の種類
| `status` | 意味 | 画面 |
|----------|------|------|
| `ok` | URLが決まった | 結果カード＋次点＋「合っていましたか？」 |
| `need_place` | 地名・観測所が決まらない | 候補ボタン（予報区・市町村・地方・観測所） |
| `choose` | 本命を決められない | 候補と絞り込み（いつ？何について？） |
| `no_match` | 該当なし | 絞り込みの選択肢 |

## 4. 画面とAPI

画面は `web/`（フレームワークなしの JavaScript）、サーバーは `server.py`（標準ライブラリの `http.server`）です。

| エンドポイント | 内容 |
|----------------|------|
| `GET /` | 画面 |
| `POST /api/guide` | 質問 → 結果。本文は JSON で `question`（200文字まで）、任意で `pick`（候補ボタンの選択）、`refine`（絞り込み）、`exclude`（却下したページ）、`scope`（地域の単位） |
| `GET /api/shortcuts` | 「よく使うページ」（地域指定のいらない固定ページ） |
| `GET /healthz` | ヘルスチェック |

```jsonc
// POST /api/guide  {"question": "名護市の警報は出ている？"}
{
  "status": "ok",
  "item": "warning_map", "title": "警報・注意報（レベル付き）", "category": "防災",
  "scope": "class20s", "place": "沖縄本島地方 名護市",
  "url": "https://www.jma.go.jp/bosai/warning/#area_type=class20s&area_code=4720900&lang=ja",
  "scopes": [{"value":"japan","label":"全国"}, {"value":"centers","label":"地方"}, ...],
  "alternatives": [ {"item": "...", "title": "...", "url": "...", "reason": "..."} ]
}
```

## 5. 安全面・方針

- **防災情報は断定しません。** 公式ページを先に・大きく示し、「このアプリは『安全』かどうかを判断しません」と表示します。
- **気象台のコメントは、気象庁の文章をそのまま**（要約・言い換えなし）、発表日時と出典を付けて表示します。取得は予報区コードが辞書にあるものだけ。HTMLは文字に変換して表示します。
- **質問文を保存・ログ出力しません。** 「はい／違う」の回答も、サーバーに保存していません（画面の中だけで絞り込みます）。
- 入力は 200文字・2KB まで、JSON のみ。`Host` 検査、CSP（`default-src 'self'`）、画面は `textContent` のみで組み立て、リンクは気象庁のドメインに限定。公開版は 1分30回/IP のレート制限と HSTS つき。
- **公開版では LLM を使いません**（費用・乱用の対策）。手元では `python3 server.py --llm` で、項目選択に Claude Code CLI を使う版を試せます。URLを作らせるのではなく、カタログの項目を選ばせるだけです。
- 利用規約: 気象庁のデータは [気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html) に従い、出典を明記しています。

## 6. 品質の確かめ方

| 方法 | 内容 |
|------|------|
| ユニットテスト | `python3 -m unittest discover -s tests`（116件。地名解決・点数・地域の単位・潮位・ランキング・コメント・サーバー・地方の対応を検査。気象庁への通信なし） |
| 評価セット | `python3 eval/run_eval.py --set questions --engine suggest`（`questions` 62問／`questions_v2` 36問／`questions_v3` 28問）。正解付きの質問で、案内先を検査する。**作者が作った易しめのセットで、実際の利用者の質問の分布ではありません** |
| カタログ検査 | `python3 tools/validate_catalog.py`（必須キー・URLのプレースホルダ・重複） |
| リンク検査 | `python3 tools/check_links.py [--notify]`: 全URLがHTTPで開くか、裏のJSONが生きているか、`area.json` などの辞書が気象庁の原本と一致するか。**毎週水曜9:30に macOS の launchd で実行**（手元のみ。`launchd/` に設定、`run_weekly_check.sh`） |

> **注意**: `#` 以降のURLは、HTTPでは「地域が効いているか」までは検査できません（地域が無視されても 200 で返る）。地域つきのURLを足すときは、ブラウザで見出しに地域名が出ることまで確認しています。

## 7. ディレクトリ構成

```
jma_navigator/
├── catalog.json         # 案内できるページの正本（27項目）
├── server.py            # Webサーバー（API・画面の配信・レート制限）
├── jnav/                # 本体（標準ライブラリのみ）
│   ├── suggest.py       #   点数付け・次点・絞り込み
│   ├── navigate.py      #   項目の選択・地域の単位・URL組み立て
│   ├── areas.py         #   地名辞書（地方・予報区・市町村）
│   ├── amedas.py  stations.py  tides.py   # アメダス・気象官署・潮位観測所
│   ├── comments.py      #   気象台からのコメントの取得・変換
│   └── llm.py           #   LLM版（手元の試用のみ）
├── web/                 # 画面（index.html / app.js / style.css）
├── data/                # 地名・観測所の辞書（気象庁のデータから作成）
├── eval/                # 評価セットと評価スクリプト
├── tools/               # カタログ検査・リンク検査・辞書の作成
├── tests/               # ユニットテスト
├── launchd/  run_weekly_check.sh   # 週次のリンク検査（macOS）
├── render.yaml          # Render（公開版）の設定
└── jma-navigator.md     # 設計メモ・Q&A・判断の経緯
```

## 8. 公開版のデプロイ（Render）

`render.yaml`（Blueprint）で、無料プラン・依存パッケージなしでデプロイできます。公開モード（環境変数 `JNAV_PUBLIC=1`）では、`0.0.0.0` と `PORT` で待ち受け、LLM を無効にし、`*.onrender.com` の `Host` を許可し、検索エンジンに載せない設定（`robots.txt`・`noindex`）にします。手順は [jma-navigator.md](jma-navigator.md) §21 を参照。

未対応・課題（詳しくは [jma-navigator.md](jma-navigator.md)）:
- 質問の保存はしていないため、実際の利用者の質問での精度は測れていません。評価セットを手元で増やして改善する方針です。
- LLM による質問の分解（「夕方」「雨でなければ」など）は、公開版では当面使いません。
- 気象庁が地方予報区や辞書を変更したときは、`data/` の更新が必要です（週次のリンク検査が `area.json` などの差分を検知します）。
- 波浪図などを「指定した場所」で開く機能（緯度経度の指定）は未対応です。
